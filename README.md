Project Description
This project is a command-line encryption and decryption program developed using Python.

It allows users to encrypt plain text into secret text and decrypt encrypted text back into its original form.

Programming Language
Python

Encryption Algorithm
Caesar Cipher

Features
- Encrypt plain text.
- Decrypt encrypted text.
- Allow users to choose a shift value.
- Preserve spaces, numbers and punctuation.
- Handle invalid shift values.
- Simple command-line interface.

How to Run the Program
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in your terminal.
4. Run the following command:

   `python caesar_cipher.py`

5. Follow the instructions displayed in the console.
